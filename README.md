# EQCAM-Opt: Energy & Quality Carbon-Aware Management

## 📌 Overview
This repository contains a robust multi-objective optimization framework designed for the sustainable management of AI-infrastructure operations. The core problem addresses the critical trade-offs between **Energy Efficiency**, **Carbon Footprint Reduction (Carbon-deficit)**, and **Operational Reliability** under compound uncertainties such as weather variations, dynamic AI workloads, and grid-risk categories (RAC).

The highlight of this project is the implementation of a novel optimization algorithm: **CL-NSGA-II** (Chaotic-Levy Non-dominated Sorting Genetic Algorithm II). This algorithm augments the classical NSGA-II framework with:
1. **Logistic-Chaotic Initialization & Perturbation:** Enhances population diversification and avoids early convergence.
2. **Adaptive Lévy-flight Long-jump Mutation:** Balances global exploration and local exploitation through a dynamically decaying activation probability across generations.

The algorithm's performance is rigorously benchmarked against classical multi-objective evolutionary algorithms (like standard NSGA-II, SPEA2, MOEA/D) using comprehensive statistical tools (Wilcoxon signed-rank tests, Holm-Bonferroni corrections) and state-of-the-art Pareto-front convergence metrics (Hypervolume, Generational Distance, Inverted Generational Distance).

## ✨ Key Features
* **Multi-Objective Optimization**: Simultaneously minimizes energy consumption, carbon deficit, and maximizes operational reliability (3D continuous decision space).
* **Novel Algorithm (CL-NSGA-II)**: Custom implementation of NSGA-II using chaotic maps and Lévy-flight mutations.
* **Ablation Studies**: Scientifically isolates the contribution of chaotic-Lévy operators compared to the baseline NSGA-II.
* **Compound Uncertainty Handling**: Evaluates scenarios using a robust min-max aggregation stratified by empirical grid-risk categories.
* **Comprehensive Metrics & Statistical Validation**: Includes Hypervolume (HV), Generational Distance (GD), CPU Time vs. Solution Quality tradeoffs, and non-parametric statistical testing.
* **Publication-Ready Outputs**: Automatically generates LaTeX tables (using `booktabs`), high-resolution Pareto frontiers (3D scatter plots), convergence profiles, and ablation heatmaps.

## 📊 Dataset Context
The optimization uses the **EQCAM Dataset**, encompassing observations spanning from February 2022 to July 2025 at a 10-minute resolution. The dataset tracks 45 variables, including:
- **Renewables & Storage**: Solar (PV) generation, Wind generation, Battery State of Charge (SOC).
- **Load Characteristics**: Data-center IT load, Cooling load, Power Usage Effectiveness (PUE), Net Energy Balance (NEB).
- **Environmental Indices**: Pre-computed footprint indices such as REAF, SGF, WGF, SOC_F, and EEIF.

**Data Availability:**
The dataset is publicly available on Zenodo. You can download the raw data from:
🔗 **[Zenodo Record: 17711914](https://zenodo.org/records/17711914)**

To run the pipeline, download the dataset from the link above and place it in the `01_data/raw_data/` directory.

## 🚀 Setup & Installation

### Prerequisites
Make sure you have Python 3.9+ installed on your machine. 

### 1. Clone or Download the Repository
Ensure all folders (`01_data`, `02_models`, etc.) are in your working directory.

### 2. Install Dependencies
Install the required packages using the `requirements.txt` file:
```bash
pip install -r requirements.txt
```
*Key dependencies include:* `numpy`, `pandas`, `scipy`, `matplotlib`, `scikit-learn`, `scikit-posthocs`, and `nbformat`.

## 🧠 Usage & Execution
The entire pipeline from data ingestion, anomaly detection (Isolation Forest), optimization, to result visualization is orchestrated within the Jupyter Notebook.

1. Navigate to the `03_notebooks` directory.
2. Launch Jupyter:
   ```bash
   jupyter notebook main_pipeline.ipynb
   ```
3. Run the notebook sequentially. The pipeline will automatically create necessary subdirectories in `04_results` and populate them with:
   - Evaluated Pareto frontiers.
   - Comparative statistical analysis reports.
   - LaTeX formatted tables ready for research papers.
   - Exported plots and convergence diagrams.
