# 🌍 EQCAM-Opt: Energy & Quality Carbon-Aware Management 🚀

Welcome to the **EQCAM-Opt** repository! 🎉 This project provides a robust, multi-objective optimization framework specifically designed for the sustainable and efficient management of AI-infrastructure operations. 🤖💚

## 📌 Overview 🧐
Managing data centers for AI is tricky! This project addresses the critical trade-offs between three main pillars:
1. ⚡ **Energy Efficiency** 
2. 🍃 **Carbon Footprint Reduction (Carbon-deficit)**
3. ⚙️ **Operational Reliability** 

All of this is done while handling compound uncertainties like wild weather variations ⛈️, dynamic AI workloads 📈, and grid-risk categories (RAC) ⚠️.

The true star 🌟 of this project is our novel optimization algorithm: **CL-NSGA-II** (Chaotic-Levy Non-dominated Sorting Genetic Algorithm II). This algorithm supercharges the classical NSGA-II framework with:
* 🌪️ **Logistic-Chaotic Initialization & Perturbation:** Enhances population diversification and avoids getting stuck early on!
* 🦘 **Adaptive Lévy-flight Long-jump Mutation:** Balances global exploration and local exploitation through a dynamically decaying probability.

We rigorously benchmarked this against classical algorithms (like NSGA-II, SPEA2, MOEA/D) using serious statistical tools 📊 (Wilcoxon signed-rank tests, Holm-Bonferroni) and state-of-the-art Pareto-front metrics! 🏆

Because the dataset is **very heavy and large** 🐘, it is **NOT** included directly in this repository to keep things fast and clean! 

Instead, the dataset is securely hosted and publicly available on Zenodo. **You MUST download it manually before running the project.** 📥

🔗 **[Click here to download the data from Zenodo (Record: 17711914)](https://zenodo.org/records/17711914)**

Once downloaded, please place the `EQCAM_Dataset.csv` file directly inside the `01_data/raw_data/` folder. 📁

### 📊 Dataset Context 🔍
The **EQCAM Dataset** contains observations from February 2022 to July 2025 at a 10-minute resolution! ⏱️ It tracks 45 critical variables, including:
- ☀️🌬️ **Renewables & Storage**: Solar (PV), Wind generation, Battery State of Charge (SOC).
- 💻❄️ **Load Characteristics**: Data-center IT load, Cooling load, PUE, Net Energy Balance (NEB).
- 🌍 **Environmental Indices**: Pre-computed footprints like REAF, SGF, WGF, SOC_F, and EEIF.

---

## ✨ Key Features 🛠️
* 🎯 **Multi-Objective Optimization**: Minimizes energy & carbon deficit while maximizing reliability.
* 🧠 **Novel Algorithm (CL-NSGA-II)**: Custom NSGA-II with chaotic maps and Lévy-flight mutations.
* 🔬 **Ablation Studies**: Isolates the exact contribution of our chaotic-Lévy operators!
* 🎲 **Compound Uncertainty Handling**: Robust min-max aggregation for real-world unpredictability.
* 📈 **Comprehensive Metrics**: Hypervolume (HV), Generational Distance (GD), and more!
* 📄 **Publication-Ready Outputs**: Auto-generates LaTeX tables (`booktabs`), 3D Pareto fronts, and heatmaps! 🤩

## 🚀 Setup & Installation ⚙️

### 1️⃣ Prerequisites
Make sure you have **Python 3.9+** installed on your machine. 🐍

### 2️⃣ Clone or Download
Ensure all folders (`01_data`, `02_models`, etc.) are in your working directory. 📂

### 3️⃣ Install Dependencies
Install the required packages using pip:
```bash
pip install -r requirements.txt
```
*(Packages include numpy, pandas, scipy, matplotlib, scikit-learn, scikit-posthocs, and nbformat)* 📚

---

## 🧠 Usage & Execution 🏃‍♂️
Everything from data ingestion to optimization and visualization is orchestrated within a single Jupyter Notebook! 🎉

1. Download the data from Zenodo (as mentioned above) and put it in `01_data/raw_data/`. ⚠️
2. Navigate to the `03_notebooks` directory. 🧭
3. Launch Jupyter:
   ```bash
   jupyter notebook main_pipeline.ipynb
   ```
4. Run the notebook sequentially! ▶️ The pipeline will automatically populate the `04_results` folder with beautiful plots, LaTeX tables, and statistical reports. 🪄✨
